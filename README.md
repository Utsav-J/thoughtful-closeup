# Thoughtful Closeup

Remotion project: `ThoughtfulCloseup` (1920×1080, 30 fps, 60 frames / 2 seconds).

```sh
npm install
npm run studio                  # Open Remotion Studio
npm run typecheck               # Check TypeScript
npm run render                  # Render to out/thoughtful-closeup.mp4
```

Animation source: `src/ThoughtfulScene.tsx` (exports `ThoughtfulScene`).
